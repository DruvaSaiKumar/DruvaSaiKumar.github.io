How I work

On a migration, the hard part is showing the new numbers match the old ones. I build the checks in from the start.

RawSource data lands exactly as received
StagingPre-ingestion checks on files, record counts and control totals
ConformanceCleansed, standardized and reconciled against legacy
CuratedConsumption-ready datasets and models
The four warehouse layers we used on the CVS Health BigQuery migration.

Check before loading

Pre-ingestion checks and audit logging for file availability, record counts, control totals, load status and exceptions.

Compare with legacy

Record counts, duplicates, nulls and column-level comparisons between the old and new platform for each migrated dataset.

Automate the setup

Terraform for infrastructure, GitHub Actions for CI/CD, Airflow and Dataflow for orchestration.

Talk to the owners

Sort out legacy logic with data owners and analysts, and support user acceptance testing.
